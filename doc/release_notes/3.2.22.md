## LaueTools 3.2.22 — Release notes

### ⚠️ Changes in behaviour
- **Indexing and refinement use the pixel size written in the `.cor` file.** Before, `IndexSpotsSet.importdatafromfile()` took it from the detector table `dict_CCD[CCDLabel]` whenever a `CCDLabel` was given, while 2θ and χ of the spots had been computed with the value of the file. With the LaueTools default 165/2048 mm and `CCDLabel` `MARCCD165` (0.079142 mm in the table), unstrained MgO came out with about 1.3 % fake strain, or was not indexed. The table value is now used only when the file has none (`IOLaueTools.get_pixelsize()`), with a warning when the two values differ.
- **Output names keep the full file name.** `.fit`, merged `.fit`, `.res` and `.cor` names were built by cutting the input name at its first dot: `MgO.r1_0000.cor` and `MgO.r1_0001.cor` both wrote `MgO_g0.fit`, and the second overwrote the first. In the GUIs, a dot in a folder name broke the names too. `os.path.splitext()` is now used in `indexingSpotsSet`, `indexing_sequence`, the calibration and refinement GUIs, `Lauehdf5` and `Build_Summary`.
- **Python 3.9 or newer is required, and Python 3.13 and newer are allowed** (`requires-python >= 3.9`). The `< 3.13` upper bound was not needed and made pip refuse to install LaueTools on 3.13 and 3.14.
- **Quick DAXM: `coresize` is renamed `boxsize_probe`** (half size of the box: `[2, 0]` is a 5×1 box). Old configuration files with `coresize` are still read.

### New features
- **DAXM wire calibration by fluorescence** (notebook `notebooks/daxm/1_wires_calibration`):
  - *Surface layer in the fluorescence model* (`Daxm/fluolayer.py`, `CalibFluoLayer`): a uniform layer above the fluorescent material, with its thickness and the fraction of the signal it gives in each profile (e.g. oxide or contamination). Settings `fluo_layer`, `fluo_layer_max` and `fluo_layer_fixed` in the `wirescalib` section of the configuration.
  - *Fast optimizer* (`Daxm/fastcalib.py`): the amplitude, offset and layer fraction of each profile are solved exactly (non negative least squares) at each step, and the jacobian is computed in parallel. Only the wire parameters (about 20) are optimized instead of 100 to 450 parameters, so a calibration takes 30–60 s on 24 cores. The results and the `.calib` files are the same as with the legacy optimizer.
  - *Check of the fluorescence profiles* (`daxm_workflow.check_fluo_profiles()`): each profile is compared with a template of the fluorescence dip (exponential source blurred by a Gaussian, shadow of the wire). Profiles with too low contrast or signal to noise, spikes, or a dip far from or wider than predicted are reported, as are boxes containing a Laue spot. Unsuited points can be replaced by points probed along X nearby (`replace_fluo_points()`).
  - `skip_images`: the first images of a scan can be excluded (on the Zr5 grid, the wire position is wrong by about 8 µm in images 0–39 of every scan after the first one).
  - *Depth resolution* (`fluo_resolution()`): σ and FWHM along the beam, from the blur of the fluorescence dips.
  - *Calibration on magnifix* (`refine_wires_fluo_job()`, new `wirescalib` workflow of `workflowlauncher`): the calibration runs as a SLURM job on magnifix, or in the kernel.
  - *Calibration elsewhere on the sample* (`refine_wires_local()`): only `h` and `p0` are refined, starting from a reference `.calib`.
- **Quick DAXM** (`Daxm/quickdaxm.py`, notebooks `notebooks/daxm/2_quick_daxm` and `3_quick_daxm_grid`):
  - Edges of the dips at 10 % and 90 % in addition to the half height, the start (`ybeam_onset`) and end (`ybeam_end`) of each dip, and the entry − exit mismatch.
  - *Wire envelope with tilts*: fit of the lines of the abacus with the tilts `f1`, `f2` of the wires.
  - *Detector offset*: the depth origin (e.g. Zr surface) can lie below the surface where the detector was calibrated (Ge reference). The offset is added to the source of the spots for 2θ and χ (`sample: detector_offset` of the configuration; `'auto'` = thickness of the fluorescence layer + shift of `p0`).
  - *Grain thickness along the beam* from the widths of the dips of all the spots of a grain (`thickness_from_width()`, `grain_depth_summary()`, `grains_depth_table()`): mean depth, minimum and maximum depth, thickness.
  - Diagnostics: table of the dips of each spot (`dips_table()`, `plot_dips_table()`) and mismatch as a function of the image index (`mismatch_vs_image()`).
  - Peak list plot: the gnomonic panel is a square of the same size as the detector panel.
- **Indexing of the DAXM depth slices** (`daxm_workflow`, notebook `2_quick_daxm`, section 8.6):
  - `index_slices()`: indexing from scratch of all the `.cor` files of the depth slices, for several materials (e.g. Cr and Zr). `slices_ub_table()` gives the UB matrix and material of each slice (`indexing_slices/slices_ub.yaml`).
  - `group_slice_grains()`, `plot_slices_grains()`: slices with the same orientation (crystal symmetry taken into account) are grouped into grains, which are shown as a function of depth.
  - `refine_slice_grains()`: refinement of each grain from its UB matrix. Each `.fit` file is written at the depth of the grain, with the parallax correction, and ends with a DAXM block: UB matrices of the slices, depths, thickness and detector offset (`read_daxm_block()`). The list of grains is in `grains/grains.json`.
- **Unit cell views** (`unitcellview.py`, new module):
  - drawing of the unit cell of a grain (cubic or hexagonal) in the BM32 laboratory view: beam horizontal pointing left, sample surface tilted by 40°;
  - projections in the sample frame;
  - `CellBrowser`: grain by grain browser in a notebook, which keeps the point of view of the 3D plot.
- **Notebook renamed:** `notebooks/daxm/1_quick_daxm` is now `2_quick_daxm` (after `1_wires_calibration`).

### Fixes
- **DAXM element tables** (`Daxm/material/dict_datamat.py`): five entries had wrong keys (`'Tb'` for Th, `'Sr'` for Sb). They replaced the Tb and Sr entries, and Th and Sb were missing. As a result:
  - Sr had the K edge of Sb (30.49 keV instead of 16.10 keV) and its fluorescence yield;
  - Tb had the density of Th.
  
  DAXM absorption and fluorescence of Sr compounds (e.g. SrTiO3) were wrong.
- **DAXM core:** wire parameters and angles are stored as Python floats instead of numpy scalars (`wire.py`, `scan/point.py`, `calibration/calib.py`, `calibration/generic.py`).
- **indexingSpotsSet:** no `KeyError` when a grain has too few matched spots to be refined.
- **Pixel size:** `readCalibParametersInFile()` no longer raises an `UnboundLocalError` when no detector matches the pixel size.
- Image index read from `.tif` names with dots (`IOimagefile`); browsing for files in the FileSeries GUIs no longer crashes on such names.
- Quieter imports: the warnings about the optional PIL and sklearn modules, and a debug print of `indexingAnglesLUT`, are no longer printed (only with `verbose`).

- `tests/test_fitfilename.py`: two images with dotted names give two `.fit` files.
- `tests/test_daxm_elements.py`: no duplicate keys in the DAXM element tables, and the values of the elements concerned.
