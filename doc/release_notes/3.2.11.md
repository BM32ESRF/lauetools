## LaueTools 3.2.11 — Release notes

### ⚠️ Important: changed results
- **Sample-frame deviatoric strain fixed for non-orthogonal cells** (hexagonal, trigonal, monoclinic, triclinic). Before this release, strain was mixed between the direct frame (x ∥ a) and the B0 frame (x ∥ a*), so these results were wrong. Tensors are now rotated with the pure rotation part of UB (polar decomposition), so the strain tensor is exactly symmetric. Results for cubic, tetragonal and orthorhombic cells do not change.
- **FitOrient: the `T` and `Ts` strain parameters were never applied.** A string identity test (`is`) was always False. Fits that vary `T00..T22` or `Ts00..Ts22` will now give different results. `Tc` parameters were already correct.
- **Map summaries (Build_Summary): wrong strain, stress and colour columns fixed.**
  - `rlat_to_Bstar()` had been passing angles in degrees where radians were expected since 2019. This made the strain6, stress6, RSS and von Mises columns and the IPF colours (`rgb_*`) wrong.
  - `matstarlab` was transposed or built without B0.
  - Added columns were shifted by 6 or 12 positions.
  - The stiffness tensor now matches the material (`<material>.stf`, then `dict_Stiffness`). Before, `si.stf` was used by default for every material.
- **Temporary check block:** `.fit` files contain a `[TEMPORARY]` block, and summaries contain `oldstrain6_*` columns. Both hold the old sample-frame strain so you can compare it with previously published data. They will be removed in a later release.

### New features
- **New indexation notebooks** (`notebooks/indexation/`), built on `indexing_batch.py`:
  - `1_index_refine.ipynb`: batch indexing and refinement, `.cor` → `.fit`, run locally or on SLURM
  - `2_postprocess_maps.ipynb`: maps and statistics of strain, lattice parameters and orientation, including IPF maps
  - `3_segmentation_grains.ipynb`: grain segmentation (clusters), KAM, GROD and boundaries
  - Each analysis is driven by a YAML file. Start from `config_template.yaml`; there are examples for Al/Al2Cu, ZrO2, Zr, MgO, Zn and Al.
  - HTML versions with the outputs of an example run (MgO) sit next to each notebook. Proposal, date, sample and path names are anonymized.
- **Full strain assuming σ_zz = 0** (no stress normal to the sample surface):
  - New functions: `fullstrain_from_deviatoricstrain()` and `get_stiffness_matrix()` (cubic, hexagonal, tetragonal, orthorhombic, or a full 6×6 matrix).
  - The full strain, hydrostatic strain and stress (MPa) are written in `.fit` files, printed after indexing, and shown in the PlotRefineGUI / DetectorCalibration results windows.
  - `dict_Stiffness` holds elastic constants for Si, GaAs, Cu, Al, Ni, Au, Ag, W, Fe, MgO and UO2 (cubic) and for Ti, Mg, Zr, GaN and ZnO (hexagonal). These are literature values; please check them for your material.
- **Strained lattice parameters** (a, b, c, α, β, γ) computed from the full strain: `latticeparameters_from_strain()`. The reference cell is the material's entry in `dict_Materials`, assumed to be stress-free. They are written in `.fit` files, printed, and shown in the results windows.
- **Equivalent (von Mises) strain**, √(2/3 dev:dev), which does not depend on the frame. It is written in `.fit` files and shown in the results windows.
- **New module `indexing_batch.py`: batch indexing and refinement driven by a YAML configuration file** (`.cor` → `.fit`, multiprocessing):
  - Configuration: `load_config`, `check_config` and `params_from_config`.
  - Test on one image with `index_refine`, then run a whole map with `run_multiprocessing`. `summarize_results`, `save_allresults` and `load_allresults` handle the results.
  - Helpers to remove spots from `.cor` files or merge them, and quality masks for maps.
  - SLURM support: it chooses an available machine, prepares and submits jobs, follows their status, collects the results, and estimates benchmark and walltime.
  - It can also be run from the command line: `python -m LaueTools.indexing_batch --config cfg.yaml` or `--job <folder> [--chunk i --nchunks n]`.
- **New module `ipfmap.py`: inverse pole figure (IPF) colour maps.**
  - Colours follow the standard stereographic triangle (TSL/MTEX convention), along sample X, Y or Z.
  - Supported Laue groups: m-3m, 6/mmm, -3m1, 4/mmm and mmm. The group is found from the material (`laue_group_of_material`).
  - `plot_ipf_maps()` and `plot_ipf_key()` draw the maps and the colour key.
- **New module `orientationclustering.py`** for symmetry-aware orientation clustering and comparison of UB matrices.
- **New tool `scripts/notebook_to_html.py`: HTML versions of notebooks, optionally anonymized.**
  - **Default:** uses the saved outputs. ipympl figures appear as their saved image, and the cluster browsers as a static view.
  - **`--execute`:** runs a temporary copy with static figures, and accepts `-p NAME=VALUE` parameters.
  - **`--anonymize [rules.yaml]`:** replaces proposal IDs, dates, sample and dataset names, hosts and local paths. This covers the code and the printed outputs and, with `--execute`, the text drawn in the figures.
  - Example: `python -m LaueTools.scripts.notebook_to_html nb.ipynb --anonymize --execute -p CONFIG=configs/my.yaml`
- **LaueDataResultsPlots:**
  - New `LatticeParamsHistogram()` shows histograms of a, b, c, α, β, γ. Its range is set by percentiles, so outliers don't flatten the distribution.
  - `StrainMapHistogram()` now ignores masked points and NaN; before, it counted them. It shows the number of points (N) and how many fall out of range. The Gaussian fit starts from the data, and a failed fit gives NaN instead of crashing. You can give a separate `bins` setting for each of the 6 components. The mask can be 1D or 2D.
  - `LatticeParamsMap(scale='other')` fixed.
- **PeakSearchGUI: Mosaic and Monitor are preset from the BLISS scan h5 metadata:**
  - The scan command is shown next to the 'All' button.
  - The number of images per line is set from the scan.
  - 'Last' is set to the largest image index on disk.
  - A 1D scan is arranged as a nearly square map.
  - Missing images in an unfinished 2D scan are shown as blank ROIs.
- **Mosaic workflow:** missing or unreadable images give NaN ROIs. The ROI bounds check uses the detector frame size (EIGER 2162×2068). Fast mosaic respects a start index other than 0.
- **`download_examples.py`** downloads the example data used by the notebooks.
- New `Examples/CuSi/cu.stf` stiffness file.

### Installation and packaging
- New optional extras:
  - `pip install "lauetools[daxm]"` installs numba, photutils and pypubsub.
  - `pip install "lauetools[hdf5]"` installs tables.
  - `pip install "lauetools[all]"` installs both.
- `ObjectListView2` is now a required dependency, used by the PeakSearchGUI peaks list editor.
- The indexation notebooks, their README and the YAML configuration files are now included in the package.
- The README has updated installation advice (use a conda or pip environment) and links to the notebooks, including an HTML version of PixelMonitoring.
- The old modules `CrystalParameters_old`, `lauecore_old` and `cli_add_material_old` were removed.
- Jupyter checkpoint files (`.ipynb_checkpoints/`) were removed from the repository and are now ignored. The repository is about 280,000 lines lighter.

### Compatibility fixes (numpy 2, matplotlib ≥ 3.9, PyTables, scikit-image, photutils, wxPython)
- **numpy 2:** fixed uses of `np.row_stack`, `np.NaN`, `np.trapz`, `np.float`, `np.int` and `np.sometrue` across many modules.
- **matplotlib ≥ 3.5 / 3.9:**
  - ROI rectangles and texts are now removed with `artist.remove()`. Before, clicking a row of the ROI list raised a TypeError.
  - `cm.get_cmap` was replaced. Before, buildsummary, plotmap and mapanalyzer did not start.
- **PyTables 3.10+:** the installed version is now detected correctly. A string comparison had wrongly rejected these versions. The hdf5 summary (`Add_allspotsSummary_from_fitfiles`) now finds spot columns by name and reads both the old and the new `.fit` formats.
- **photutils 3.0 and scikit-image 0.26** are supported in DAXM.
- **ObjectListView 1.3.1 with wxPython 4:** resizing the PeakSearchGUI peaks list no longer raises a TypeError. The library passed float sizes to `SetSize`/`SetColumnWidth`.
- **`daxmgui` entry point fixed.** If a DAXM package is missing, a message now says which one to install.
- **BLISS paths:** dataset names containing `_` are now handled. The h5 path is taken from the scan folder.
- **Log file reader:** `npts_fast`, `npts_slow` and `scandim` are read for all scan types.
- **Folder scanning:** stricter image index detection.
- **GUI comparisons:** some string comparisons used `is` instead of `==`; this is fixed in ManualIndexFrame and SimulFrame.

### Tests
- New `tests/test_fullstrain.py`. It checks that the full strain is recovered, that σ_zz = 0, and the lattice parameters, for several crystal symmetries.
