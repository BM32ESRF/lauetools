## LaueTools 3.2.16 — Release notes

### ⚠️ Changes in behaviour
- **mainGUI may use a copy of `Examples/Ge` in your home folder.** If LaueTools is installed in a read-only folder (for example a shared python environment), Detector Calibration and Autoindexation open the default Ge peak lists from `~/.lauetools/Examples/Ge`. Their results are written there too. The default files are copied there the first time, and later copies never overwrite them. If the installed `LaueTools/Examples/Ge` folder is writable (git clone, your own environment), it is used as before.

### New features
- **New material `NiMnGa_base110`** (lattice 4.26, 5.51, 20.69 Å, β = 90.3°, no extinction rule) in `materials.yaml` and in the built-in materials dictionary. The built-in dictionary also gets `NiMnGa_theo` and `NiMnGa_exp` (extinction rule h+k=2n).
- **`cli.writable_examples_folder(name)`** returns a folder of default example files where the GUIs can write: the installed `Examples/<name>` if it is writable, otherwise `~/.lauetools/Examples/<name>`, where the default files are copied. The default files of each folder are listed in `cli.DEFAULT_EXAMPLES`.

### Fixes
- **Detector Calibration and Autoindexation from mainGUI after `pip install`:** the default Ge peak lists `img_Ge_sCMOS_0000_181peaks.cor` and `img_Ge_sCMOS_0000_2peaks.cor` were missing from the package, so these boards could not open their default data.
- **No more folder dialog with a read-only installation:** opening the default data used to ask for a folder to write the results. The writable copy in `~/.lauetools/Examples/Ge` is now used.

### Packaging
- **New package data:** `Examples/Ge/img_Ge_sCMOS_0000_181peaks.cor` (27 kB) and `Examples/Ge/img_Ge_sCMOS_0000_2peaks.cor` (1 kB).
- **Narrower `*.cor` exclusion:** `exclude-package-data` excluded `*.cor` files in every subfolder of `LaueTools`, including the files listed in `package-data`. It now applies only to `scripts/` and `notebooks/`.
