## LaueTools 3.2.19 — Release notes

### ⚠️ Changes in behaviour
- **Tutorial notebooks of `notebooks/` are anonymized.** Data paths, proposal numbers, sample names and dates are replaced by placeholders such as `<proposal>` or `<inhouse path>`: set your own paths before running them. The saved states of their widgets are removed, which makes them up to 4.5 MB smaller.
- **`requirements.txt` no longer contains the GUI packages.** It lists the packages for the notebooks and scripts. The GUI needs `requirements-gui.txt` (wxPython and ObjectListView2).

### New features
- **Export of notebooks to HTML and PDF** (`notebook_export.py`, command `lauetools-export-notebook`):
  - `lauetools-export-notebook my.ipynb` writes `my.html` and `my.pdf` next to the notebook, from its saved outputs. Options: `--to pdf`, `--outdir`, `--execute`.
  - `export_this_notebook()` exports the running notebook. It is the last cell of the notebooks of `quickstart`, `peaksearch`, `indexation` and `mosaicgrainimaging`. The path of the notebook is found in VS Code, JupyterLab and Jupyter Notebook. Save the notebook (Ctrl+S) before running this cell.
  - PDF with the first available of: headless Chromium (`pip install "lauetools[webpdf]"`, then `playwright install chromium`), xelatex, or LibreOffice. With LibreOffice, wide figures are resized to the page width.
- **Mosaic grain imaging notebook** (`notebooks/mosaicgrainimaging/mosaic_grainimaging.ipynb`, module `grainimaging.py`): intensities of detector ROIs over all the images of a map. `lauetools-copy` copies it.

### Packaging
- **New command:** `lauetools-export-notebook`.
- **New optional dependencies:** `pip install "lauetools[notebook]"` (pandas, ipympl, ipywidgets, nbconvert, nbformat) and `"lauetools[webpdf]"` (PDF with a headless Chromium). `"lauetools[all]"` includes `notebook`.
- **New file `requirements-gui.txt`**: `requirements.txt` plus wxPython and ObjectListView2. ObjectListView2 is not on conda-forge, so it was removed from `conda_requirements.txt`; `INSTALL.readme` installs it with pip after wxPython. Its installation order does not matter: it is a pure-python package without declared dependencies, imported only by the GUI.
- **Notebooks only, without wxPython:** see `INSTALL.readme` (`pip install --no-deps lauetools`, then `pip install -r requirements.txt pandas ipympl ipywidgets`).
- **New package data:** `notebooks/mosaicgrainimaging/*.ipynb`, `*.md`.
- **Excluded from the package:** copies of the working notebooks `*.local*.ipynb` (e.g. `<name>.local-Copy1.ipynb`), and the `dev_*` studies of the notebooks folders.
- **New modules:** `notebook_export`, `grainimaging`.
